# NarkoFarm Web v0.4

Кликабельный мобильный/десктопный прототип.

- Навигация между Главной, Фермой, Городом, Сезоном и Рейтингом без перезагрузки.
- Мобильная нижняя навигация.
- Кликабельные карточки и грядки.
- Telegram и игровые действия пока являются заглушками.
- CSS/JS встроены в index.html для корректного открытия через iPhone «Файлы».

Следующий этап: Telegram Login + API + реальные данные NarkoFarm.
