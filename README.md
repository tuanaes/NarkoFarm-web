# NarkoFarm Web v0.5 — Farm

Веб-версия фермы NarkoFarm с механиками, повторяющими актуальный Telegram-бот.

Сейчас это frontend/demo:
- 2 стартовые грядки, максимум 12;
- культуры и таймеры из бота;
- посадка одной грядки и «Посадить всё»;
- «Собрать всё»;
- комбикорм +30% урожая;
- катализатор -25% оставшегося времени, минимум 1 минута;
- XP и повышение уровня;
- сохранение демо-состояния в localStorage.

Следующий этап — Telegram авторизация и подключение к реальным данным бота.
